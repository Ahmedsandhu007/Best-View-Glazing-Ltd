Repository secrets

The keys a store's jobs sign in with (OnBuy keys, the Google service account, Keepa). Typed here they are sealed with the repository's public key on this machine and only the ciphertext goes to GitHub - the dashboard never stores, logs or shows a value, and GitHub never returns one: the list shows names and dates only. Set the same names every store uses; a new store is ready when none are missing.

Add a store

Onboards a store to this dashboard only: every page grows its chip at once, and the registry file keeps it for the next start. The GitHub token must already reach the repository (it is checked before anything is saved); the repository's own secrets and workflows are set up on GitHub as with every store. Removing a store changes nothing on GitHub or OnBuy either - its jobs keep running, the dashboard just stops watching.

Other running copies of the dashboard see it after their restart.
