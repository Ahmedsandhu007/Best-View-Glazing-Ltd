What this page shows

One card per store with the latest result of each automatic job and how long ago it ran. Green = it worked, red = it failed, orange stale = it has not run as often as it should, grey never = no run found. The card also says what is running or waiting in the store's queue. Nothing on this page changes anything - click a store's name for its buttons, or use the menu above for the cards (Pricing, Fees, Sale, Buy Box, Catalogue, Delete).
